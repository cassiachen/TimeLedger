# 产品需求文档 v1.0 —— 时账 TimeLedger

## 1. 产品定位

- **产品名称**：时账 TimeLedger
- **产品类型**：个人记账 + 时间价值管理
- **核心价值**：将消费金额自动换算为对应的工作时间，让用户知道一笔消费实际花费了多少时间。
- **核心公式**：消费金额 ÷ 时薪 = 消费时间成本

## 2. 目标用户

20–30 岁一二线城市年轻上班族。

特征：
- 有稳定工资收入
- 有记账或存钱需求
- 关注消费控制
- 不喜欢复杂财务工具

## 3. 核心产品闭环

记录消费 → 自动换算时间 → 查看消费结构 → 形成消费认知

核心目标：降低记账操作成本，提高消费决策意识。

## 4. 首页

### 4.1 今日数据
- 今日收入
- 今日支出
- 今日净值
- 今日消费对应工作时间

示例：
```
今日收入 ¥364
今日支出 ¥126
今日净值 +¥238
今日消费 ≈ 2小时46分钟
```

### 4.2 本月数据
- 本月收入
- 本月支出
- 本月结余
- 本月消费时间

### 4.3 今日账单
按时间展示，例如：
```
午餐 ¥28 ≈ 37分钟
咖啡 ¥18 ≈ 24分钟
地铁 ¥6 ≈ 8分钟
```

## 5. 记账功能

### 5.1 账单类型
- 支出
- 收入
- 转账

### 5.2 支出字段
必填：金额
自动/可选：分类、时间、账户、商户、备注

### 5.3 收入分类
工资 / 奖金 / 兼职 / 红包 / 退款 / 其他

### 5.4 支出分类
默认：餐饮 / 交通 / 居住 / 购物 / 娱乐 / 学习 / 医疗 / 宠物 / 数码 / 其他
支持自定义分类。

## 6. 时间价值

用户首次使用设置：月收入、每月工作天数、每天工作小时数

系统计算：时薪 = 月收入 ÷ 月工作总小时

示例：
```
月收入 ¥8,000
22 天/月
8 小时/天
≈ ¥45.45/小时

消费 ¥28 ≈ 37分钟工作时间
```

## 7. 账户

支持：微信 / 支付宝 / 银行卡 / 现金 / 信用卡 / 其他

账户之间转账：不计入收入或支出。

## 8. 账单

### 8.1 列表
按照日期 + 时间排序，显示：分类、商户/备注、金额、时间成本、账户

### 8.2 操作
支持：编辑、删除、搜索、筛选

筛选条件：日期、收入/支出、分类、账户、金额

## 9. 统计

### 9.1 本月概览
总收入、总支出、总结余、总消费时间

### 9.2 分类统计
例如：
```
餐饮 ¥860 ≈ 18小时55分钟
购物 ¥520 ≈ 11小时26分钟
交通 ¥320 ≈ 7小时02分钟
```

### 9.3 趋势
日支出趋势、月支出趋势、月收入趋势、消费时间趋势

### 9.4 环比
例如：本月支出较上月 -11.5%

## 10. 无感记账

- **V1**：手动快速记账（输入金额 → 保存，分类尽可能自动推荐）
- **V2**：截图 OCR（识别金额、商户、时间、支付方式）
- **V3**：分享记账（从支付凭证/截图直接分享 → 时账，自动识别生成账单）
- **V4**：探索 Android 通知读取 / iOS Shortcuts / App Intents 等系统级自动化

最终目标：让用户尽可能少主动操作。

## 11. 周报 / 月报

**免费**：基础账单、首页数据、基础统计、时间换算

**会员**：
- 周报：收入、支出、结余、消费时间、分类变化
- 月报：月度消费分析、同比/环比、消费时间结构、消费趋势、AI 消费分析

## 12. 商业模式

To C，基础功能免费。会员订阅：周报 / 月报 / 高级统计 / AI 分析 / 高级数据功能。

## 13. MVP 功能（第一版）

**P0**：
1. 用户注册/登录
2. 工资设置
3. 时薪计算
4. 手动记账
5. 收入/支出/转账
6. 分类
7. 账户
8. 首页
9. 账单列表
10. 时间成本换算
11. 基础统计
12. 数据云同步

**暂不做**：OCR、自动读取通知、AI、周报/月报、复杂预算系统

> 本仓库当前版本（v0.1 原型）实现了 P0 中除「用户注册/登录」「数据云同步」外的全部功能，
> 数据存储在浏览器 localStorage，作为可交互 UI 原型驱动后续开发。

## 14. 产品核心差异

传统记账：你花了 ¥199。
时账：你花了 ¥199 ≈ 4小时22分钟工作时间。

核心不是「记录钱」，而是把钱转换成用户可以感知的时间。
